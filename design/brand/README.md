# LocAI ロゴ

こまめと「LocAI」を組み合わせたアプリアイコン。KDU Mobile公式アイコン（https://kdu.mobi/img/apple-touch-icon.png）の輪郭線・色面の陰影・文字との構成を参考にし、LocAIのキャラクターと緑で制作しました。画像生成の組み込みツールを使用。写実的な玩具風の質感を抑えたイラスト調の案です。原寸PNGはこのフォルダ、ヘッダー用WebPはpublic/brand、ブラウザとホーム画面用PNGはsrc/appにあります。

2026-10-21：ヘッダー用に四角い緑背景を除いた透過版を追加。組み込み画像編集ツールを使用し、編集指示はtransparency-edit-prompt.txtに保存。ブラウザ・ホーム画面のアイコンは従来の画像。
